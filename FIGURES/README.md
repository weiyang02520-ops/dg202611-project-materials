# Figures policy and index

正式设计图的 canonical 位置：

`FORMAL_SUBMISSION_REBUILD/FORMAL_FIGURES_P1/`

当前包含 7 幅可编辑 SVG、7 幅 300 dpi PNG、7 份 figure spec，以及统一 style guide 和 self-check。这里不重复复制相同资产，以避免双 canonical。

只允许加入：项目自有且确认可公开的照片、明确标注为 CAD/URDF/SIMULATION 的衍生图、或新绘制的设计图。第三方参考图片、来源不明截图、私人照片及把仿真图冒充实车的材料不得加入。
