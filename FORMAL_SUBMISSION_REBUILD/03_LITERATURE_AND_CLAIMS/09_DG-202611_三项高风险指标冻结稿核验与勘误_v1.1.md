# 3. 特征重复率：核验结果

## V-REP-01 min-denominator确有文献基础

2022论文：
**Two-Fold and Symmetric Repeatability Rates for Comparing Keypoint Detectors**

DOI：
`10.32604/cmc.2022.031602`

原文明确讨论多种repeatability定义，并指出常见归一化之一使用：

`N_mn = min(N_a, N_b)`

作为分母。

状态：
`PRIMARY_SOURCE_VERIFIED`

因此DG主指标：

`R_min = M / min(N1,N2)`

具有明确经典/后续文献依据。

---

## V-REP-02 平均数量归一化也有文献依据

同一论文还讨论：

`N_av = (N_a + N_b)/2`

作为另一种normalization。

在DG中使用：

`R_avg = 2M / (N1+N2)`

数学上等价于：
`M / N_av`

前提是DG采用同一组一对一重复特征对 M。

状态：
`PROJECT_COMPANION_METRIC_WITH_LITERATURE_BASIS`

重要修正：

> 正式方案书不要把 `R_avg` 称为“该论文唯一推荐的symmetric repeatability公式”。

论文的完整symmetric处理还涉及双方向重复检测计数。

我们采用 `R_avg` 的目的，是：

> 对 `R_min` 做一个更保守、对两帧特征数不平衡更敏感的项目伴随统计。

---

## V-REP-03 3D keypoint确实可以有很高repeatability，但强依赖扰动条件

2025 IJCV：
**A Fast and Lightweight 3D Keypoint Detector**

公开全文表格显示：
在KeypointNet原始条件和若干distance threshold下，部分方法repeatability可接近甚至达到1.0；
但在downsample/noise扰动后显著下降。

状态：
`PRIMARY_SOURCE_VERIFIED`

因此以下结论保留：

> “95%存在文献可行性”可以说。

但不能说：

> “动态机器人场景下95%是轻易可以达到的普遍SOTA。”

# 4. 重定位 >95%：核验结果

## V-REL-01 成功率高度依赖误差阈值

论文：
**A Real-Time Global Re-Localization Framework for a 3D LiDAR-Based Navigation System**

Sensors, 2024

DOI：
`10.3390/s24196288`

原文明确：
- simulation，1.0m threshold：99%
- Newer College，1.0m threshold：94.67%
- exhaustive matching，1.0m threshold：97.83%

状态：
`PRIMARY_SOURCE_VERIFIED`

所以：

> success rate必须和threshold绑定。

这一原则冻结。

## V-REL-02 0.3m + π/8 是真实文献案例

2026 Scientific Reports：
**Object-aware semantic mapping using probability density functions for indoor relocalization and path planning**

DOI：
`10.1038/s41598-026-40498-3`

原文定义一次定位成功为：
- position error <0.3m
- orientation error <π/8

状态：
`PRIMARY_SOURCE_VERIFIED`

但：

> 该论文并没有规定DG必须使用0.3m。

它只证明0.3m量级的global relocalization success阈值在近期正式论文中确实存在。

## V-REL-03 主动定位文献成立

CoRL 2025：
**ActLoc: Learning to Localize on the Move via Active Viewpoint Selection**

核心：
- 不同viewpoint具有不同定位信息价值
- 将localization accuracy distribution纳入规划

状态：
`PRIMARY_SOURCE_VERIFIED`

因此DG把：
- 安全停止
- 旋转
- 搜索

写成“具身主动定位/主动重定位”的总体思路，是有近期高水平研究依据的。

但具体动作策略仍然是DG自己的设计。

# 5. DG主重定位判据的来源标签修正

v1.0冻结：

- `e_xy ≤0.30m`
- `e_yaw ≤10°`
- `T_reloc ≤30s`
- `T_hold ≥10s`

从现在起必须标记为：

`DG_PROJECT_PRE_REGISTERED_PRIMARY_CRITERION`

不是：

`LITERATURE_STANDARD`

其中：
- 0.30m有近期文献案例支撑其量级合理；
- 10°、30s、10s是DG为了形成清晰、可复现、不会事后改动的项目实验协议而主动冻结。

若官方后来给出测试规范：
官方覆盖DG内部定义。

# 6. 旧材料与新冻结稿之间的关系

旧v0.2已有repeatability定义：
- common visibility
- motion compensation
- one-to-one matching
- `M/min(N1,N2)`
- INVALID if denominator=0
- pooled result

这些方法学内容本身是有价值的，可迁移。旧稿也明确指出`temporal_match_ratio`不等于官方特征级repeatability。该边界继续保留。

旧vCurrent已有重定位统计逻辑：
- 一个外部trial可包含多个attempt
- 最终RECOVERED只是必要非充分条件
- 需要独立真值
- 超时/人工接管/最终失败计失败
- 建议Wilson/Clopper–Pearson区间

这些方法学内容可以迁移。

但旧稿中所有“当前完成状态”不迁入正式答卷。
