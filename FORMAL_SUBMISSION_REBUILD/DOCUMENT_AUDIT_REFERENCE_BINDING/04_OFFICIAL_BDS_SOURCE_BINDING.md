# 北斗短报文官方来源精确绑定

核验日期：2026-08-31  
结论：BDS-ASA-1.0、国务院白皮书及 3 项国家标准均已绑定官方原始落点。

## 1. BDS-ASA-1.0

- 精确题名：北斗卫星导航系统应用服务体系（1.0版）
- 文件代号：BDS-ASA-1.0
- 发布者：中国卫星导航系统管理办公室
- 日期：2019-12
- 官方目录页：http://www.beidou.gov.cn/xt/gfxz/index_1.html
- 官方 PDF：http://www.beidou.gov.cn/xt/gfxz/201912/P020191227332811335890.pdf
- PDF 物理页 1：题名、版本、发布者、2019 年 12 月。
- PDF 物理页 3：文件代号 BDS-ASA-1.0 与目录。
- §2.2、印刷页 4 / PDF 物理页 8：表5（RSMC）与表6（GSMC）。

### 表5：RSMC，区域短报文

| 性能项 | 官方值 |
|---|---|
| 服务范围/对象 | GEO 卫星，面向中国及周边地区用户 |
| 服务成功率 | ≥95% |
| 服务频度 | 一般 1 次/30 秒，最高 1 次/1 秒 |
| 响应时延 | ≤1 秒 |
| 终端发射功率 | ≤3 W |
| 服务容量 | 上行 1200 万次/小时；下行 600 万次/小时 |
| 单次报文最大长度 | 14000 bit，约 1000 个汉字 |

### 表6：GSMC，全球短报文

| 性能项 | 官方值 |
|---|---|
| 服务范围/对象 | MEO 卫星，面向位于地表及其以上 1000 km 空间的特许用户 |
| 服务成功率 | ≥95% |
| 响应时延 | 一般优于 1 分钟 |
| 终端发射功率 | ≤10 W |
| 服务容量 | 上行 30 万次/小时；下行 20 万次/小时 |
| 单次报文最大长度 | 560 bit，约 40 个汉字 |

边界：正文赛题语境为北斗三号区域短报文，优先引用 RSMC 表5。不得把 GSMC 的 560 bit、分钟级响应与 RSMC 的 14000 bit、秒级响应混成一个 profile；官方系统指标也不自动证明特定终端、授权账户或项目集成达到同一性能。

## 2. 《新时代的中国北斗》

- 精确题名：新时代的中国北斗
- 发布者：中华人民共和国国务院新闻办公室
- 日期：2022-11
- 官方全文：https://www.gov.cn/zhengce/2022-11/04/content_5724523.htm
- 页面标题：新时代的中国北斗_白皮书_中国政府网
- 相关位置：第二部分“跻身世界一流的中国北斗”之“（三）系统服务优质多样”。

该官方全文区分：

- 全球短报文通信：最大单次 560 bit（40 个汉字）。
- 区域短报文通信：面向中国及周边地区，最大单次 14000 bit（1000 个汉字），具备文字、图片、语音等传输能力。

白皮书用于确认服务类型、服务区域与最大单次报文长度；频度、时延、发射功率和系统容量优先绑定 BDS-ASA-1.0 表5/表6。

## 4. 对正文第154行的推荐证据组合

- “已形成应用服务体系”：REF-OFF-02（BDS-ASA-1.0）。
- “全球/区域服务边界与最大单次长度”：REF-OFF-03（国务院白皮书）并与 BDS-ASA 表5/表6交叉。
- “相关国家标准包括……”：REF-STD-01、REF-STD-02、REF-STD-03。
- “容量、频度、终端授权等约束”：容量/频度用 BDS-ASA；授权/终端可用性必须由实际终端合同、账号 profile 或测试记录另证。
