# 1. 全书唯一主线

复杂环境导致BDS、LiDAR和其他定位观测发生不同类型退化  
→ 观测首先经过质量判断  
→ 多源融合根据可信度自适应参与、降权或拒绝  
→ LiDAR侧通过动态/异常反射抑制、稳定特征和几何不确定度提升约束质量  
→ 当被动融合仍不足以维持可靠定位时，机器人主动改变运动和视角获取更有辨识度的观测  
→ 重定位候选经过置信度、多帧和多源一致性验证  
→ 成功后平滑恢复定位并安全交还导航  
→ UWB作为局部绝对定位观测，同样遵循质量感知接入  
→ 北斗短报文承担通信受限场景下关键状态与任务信息传递。
