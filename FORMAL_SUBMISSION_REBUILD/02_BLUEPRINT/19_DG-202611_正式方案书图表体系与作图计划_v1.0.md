# DG-202611 正式方案书图表体系与作图计划 v1.0

**状态：CURRENT / FORMAL_SUBMISSION_DESIGN**  
**用途：统一正式方案书全部图、表、公式和实验可视化。**  
**原则：图表服务于评分点，不做装饰性堆图。**

---

# 1. 总体原则

正式稿中的图表必须回答至少一个问题：

- 系统是什么？
- 技术路线怎么闭环？
- 三个模型分别如何工作？
- 样机怎么实现？
- 官方指标如何验证？
- 文献与项目方案相比有什么优势？

每张图都要有明确作用。

禁止：

- 为了“好看”塞大量无信息装饰；
- 直接贴代码截图代替系统图；
- 低清晰度终端截图；
- 把 Gazebo 截图写成实机图；
- 把内部流程图直接放进正式稿；
- 出现 Claude / Codex / ZCode / DSH / Package A 等内部名词。

## FIG-02 三个核心模型协同图

### 放置
第3章结尾。

### 结构

```text
模型1：连续高精度定位
      ↑        ↓
模型2：稳定LiDAR特征
      ↑        ↓
模型3：具身主动重定位
```

再标：

- 模型2向模型1提供更可信 LiDAR 观测；
- 模型1发现系统退化触发模型3；
- 模型3恢复可信位姿后返回模型1；
- 三者共同服务官方指标。
