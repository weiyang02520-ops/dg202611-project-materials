# DG-202611 正式设计图统一视觉规范（P1）

## 1. 画布与输出

- SVG 画布：`160 mm × 90 mm`，`viewBox="0 0 1600 900"`，横向 16:9。
- Word 建议插入宽度：`15.8 cm`，锁定纵横比，采用嵌入型或上下型环绕。
- PNG 预览：`1866 × 1050 px`，写入 `300 dpi` 元数据，对应约 15.8 cm 正文版心宽度。
- SVG 不嵌入外部图片，不引用在线字体；所有文字均保留为可编辑 `<text>` 元素。
- 字体回退：Microsoft YaHei → Noto Sans CJK SC → SimHei → sans-serif。正式装配机缺少首选字体时应先复核换行。
- 最小字号：29 个 SVG 单位，按 15.8 cm 入稿约 8.1 pt；正文节点通常 30–31 单位，标题 40 单位。

## 2. 颜色与非颜色编码

| 语义 | 主色 | 辅助编码 |
|---|---|---|
| 系统主流程、模型和状态 | 深蓝 `#17365D` / 蓝 `#2F5597` | 实线边框、实线箭头、矩形节点 |
| 可信观测、有效信息、恢复成功 | 青绿 `#0F6B6D` / 浅青 `#E7F5F3` | 圆角节点、实线 |
| 告警、条件、短报文、待验证 | 橙 `#C46A00` / 浅橙 `#FFF0D9` | 虚线边界或橙色箭头 |
| 拒绝、失败、SAFE_FAIL | 红 `#A61B1B` / 浅红 `#FCE8E6` | 红色虚线失败路径、加粗边框 |
| 上下文、普通输入、边界说明 | 灰 `#667085` / 浅灰 `#F5F7FA` | 灰色细边、虚线边界 |

黑白打印时不依赖颜色：主链为实线箭头，条件或待验证为虚线边界，失败为虚线分支，成功状态使用胶囊形，普通处理使用矩形。

## 3. 信息层级

1. 顶部：图号与标题，回答“本图解决什么问题”。
2. 中部：唯一主阅读方向；流程图优先左→右，状态机按明确闭环箭头阅读。
3. 底部或侧栏：条件、证据边界和“待正式验证”声明。

每图最多约 12 个主节点，辅助标签不建立新的并行主链。设计事实、工程事实和实验结果严格分离。

## 4. 语言与标注

- 中文为主；协议名、状态名和实验编号保留英文以便与正文一一映射。
- “目标”“待正式验证”“条件接入”必须显式显示，不得以颜色暗示代替文字。
- `PASS / FAIL / UNDETERMINED` 仅表示正式评价的判定域，不表示本轮已有判定结果。
- RSMC 与 GSMC 不混写；北斗短报文链不得进入定位观测融合层。
- 禁止出现内部任务编号、开发日志、草稿包名和未经真实实验支持的性能结论。

## 5. Word 总装

- Word 中另用自动题注生成正式图题；SVG 内标题用于资产独立审阅，可在最终模板明确要求时保留或隐藏。
- 插图后更新交叉引用，检查 SVG 字体替换、箭头、透明度和边框。
- 若缩窄到小于 15.8 cm，必须重新检查最小字号；不得直接压缩至不可读。
- PNG 只作预览/兼容回退，正式 Word 优先插入 SVG。
